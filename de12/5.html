使い方


STEP1: vscodeのターミナルで"source .venv-1/bin/activate"を実行して環境を有効化


STEP2: "export OPENAI_API_KEY="sk-あなたのキー""をターミナルで実行する


STEP3: "streamlit run app.py"を実行してマッチングを開始する


*注意: streamlitをインストールしていない場合は、"pip install streamlit"を実行してインストールします


*注意: 画面のソースコードなどをXcodeに入れないと実際にプレイはできません
